- 복사한 원본 35개 파일의 SHA-256을 대조해 원본 내용이 변경되지 않았음을 확인했습니다.
- Python 파일 30개와 노트북 5개 내 코드 셀 88개의 문법을 확인했습니다.
- 노트북 실행 출력과 실행 번호를 제거했습니다.
- 코드에 포함된 OpenAI/Hugging Face 인증키 4곳을 환경변수 참조로 바꾸고 정리본에서 알려진 키 패턴이 남아 있지 않은지 검사했습니다.
- `python scripts/show_results.py`를 실행해 14개 집계 조건이 표시되는 것을 확인했습니다.
- README의 모델·프롬프트·문항 유형별 정확도는 최종 Notion 기록 및 원본 분석 노트북에 저장된 출력과 대조했습니다.
- MultifacetEval 배포본의 MIT 라이선스 고지를 보존했습니다.

## 실행하지 않은 검증

- 모델 API 호출, GPU 추론, 전체 문항 생성 및 원본 응답 재평가.
- 모든 의존성 조합의 설치·통합 테스트. 원래 실험 환경의 lockfile은 발견되지 않았습니다.
- 원본 최종 Excel 집계 파일의 재계산. 클라우드 파일 읽기에서 시간 초과가 발생하여 이번 검증은 저장된 노트북 출력과 연구 기록을 사용했습니다.

따라서 문법 검사 통과는 전체 연구 파이프라인의 실행 성공을 의미하지 않습니다. 입력 데이터와 실험 설정을 준비하는 방법은 `REPRODUCTION.md`에 설명했습니다.
